# Language Survival

A Minecraft Fabric mod that makes you practice languages while playing Minecraft survival mode!

Whenever you pick up an item, you have a limited amount of time to verbally pronounce its name in your selected language. Get it right and keep the item. Get it wrong, and you lose it!

Currently supports Czech, French, German, Italian, Japanese, and Spanish.

**Minecraft version:** Java Edition 1.21.1  
**Mod loader:** Fabric

## Download

Go to the [Releases](https://github.com/filipbudd/language-survival/releases) page to download the latest version.

## Installation

You'll need [Fabric Loader](https://fabricmc.net/use/installer/) and [Fabric API](https://modrinth.com/mod/fabric-api/version/0.116.17%2B1.21.1).

1. Install Fabric Loader for Minecraft 1.21.1.
2. Download Fabric API and place it in your `mods` folder.
3. Download the Language Survival JAR from Releases and place it in the same folder.
4. Launch Minecraft and select a language!

The mod downloads the required speech recognition model automatically. A microphone is required.
